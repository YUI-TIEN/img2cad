# img2cad agent instructions

For requests that turn an image, sketch, or drawing into editable CAD, read and follow [`skills/img2cad/SKILL.md`](skills/img2cad/SKILL.md). It is the repository's agent workflow contract; use the local CLI and schema it names rather than improvising a separate pipeline.

The root [`README.md`](README.md) describes project scope. [`benchmark/README.md`](benchmark/README.md) documents frozen cases and repeat-run validation. A passing manifest records gate attestations; inspect the CAD runner's measured geometry and the actual preview/review separately before making acceptance claims.
